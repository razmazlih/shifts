# קבצים ומיגרציות — סבב שיבוץ בטוח ותהליכי עובדים

בסיס ההשוואה המקומי הוא `19022e1`, בעל אותה תמונת קוד כמו `origin/main` ב־`bc3a485` בעת תחילת העבודה. הקבצים שלהלן כוללים שלבים א׳ וב׳. אין שינוי בסודות או בקובצי הסביבה, ולא נוספו תלויות ייצור.

## מיגרציות

- [הצעות שיבוץ](../prisma/migrations/20261106000000_schedule_proposals/migration.sql): טבלה נפרדת להצעה שנבדקה, תוקף, מצב שימוש ונתוני אימות.
- [תהליכי עובדים](../prisma/migrations/20261106010000_employee_workflows/migration.sql): בקשות, עדכונים, גרסאות תבנית ומועדפות אישיות.

שתיהן מוסיפות נתונים לסכמה. השיבוצים והפרסומים הקיימים אינם נמחקים. נעילה ושיוך אילוץ לבקשה הם שדות JSON אופציונליים ותואמים לנתונים קודמים. המיגרציות הורצו רק במסד הבדיקות המקומי.
